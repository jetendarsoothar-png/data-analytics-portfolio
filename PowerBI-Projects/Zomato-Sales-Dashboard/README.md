🍽️ Zomato Insights Dashboard

## Project Overview

An interactive Power BI dashboard developed to analyze Zomato restaurant and order data, providing insights into restaurant performance, customer satisfaction, orders, ratings, cuisine preferences, and delivery times.

## Tools Used

- Power BI
- Excel
- Power Query
- DAX

## Dashboard Analysis

This dashboard provides insights into:

- Total Orders
- Customer Satisfaction
- Average Delivery Time
- Average Order Value
- Discount Utilization
- Top 10 Restaurants
- Total Orders Trend by Year
- Ratings Distribution
- Cuisine-wise Order Analysis
- Restaurant-wise Delivery Time
- Restaurant and Customer Location Analysis

## Skills Demonstrated

- Data Cleaning
- Data Transformation
- Data Modeling
- DAX Measures
- KPI Development
- Data Visualization
- Interactive Dashboard Development
- Business Intelligence Reporting
- Trend and Performance Analysis
