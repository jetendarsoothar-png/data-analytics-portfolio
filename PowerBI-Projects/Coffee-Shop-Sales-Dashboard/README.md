# ☕ Coffee Shop Sales Dashboard

## Project Overview

An interactive Power BI dashboard created to analyze coffee shop sales performance and generate business insights.

## Tools Used

- Power BI
- Excel
- Power Query
- DAX

## Dashboard Analysis

This dashboard provides insights into:

- Total Sales
- Total Orders
- Revenue Trends
- Product Performance
- Sales Analysis by Time
- Customer Purchasing Patterns

## Skills Demonstrated

- Data Cleaning
- Data Transformation
- Data Modeling
- DAX Measures
- Data Visualization
- Business Intelligence Reporting
