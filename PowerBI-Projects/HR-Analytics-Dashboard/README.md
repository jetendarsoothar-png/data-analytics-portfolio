# 👥 HR Analytics Dashboard

## Project Overview

An interactive Power BI dashboard developed to analyze employee data and provide insights into workforce demographics, employee performance, recruitment, salaries, satisfaction, and employee status across different departments and years.

## Tools Used

- Power BI
- Excel
- Power Query
- DAX

## Dashboard Analysis

This dashboard provides insights into:

- Total Headcount
- Active and Terminated Employees
- Gender Distribution
- Total Salary
- Employee Performance
- Marital Status
- Employee Satisfaction
- Department-wise Employee Analysis
- Recruitment Sources
- Employee Location by State
- Year-wise HR Analysis
- Department and Year-based Filtering

## Skills Demonstrated

- Data Cleaning
- Data Transformation
- Data Modeling
- DAX Measures
- KPI Development
- HR Data Analysis
- Data Visualization
- Interactive Dashboard Development
- Business Intelligence Reporting
- Workforce Performance Analysis
