# 🛒 Online Retail Sales Dashboard

## Project Overview

An interactive Power BI dashboard developed to analyze online retail sales data and identify business trends, customer behavior, and sales performance.

## Tools Used

- Power BI
- Excel
- Power Query
- DAX

## Dashboard Analysis

This dashboard provides insights into:

- Total Revenue
- Total Orders
- Customer Analysis
- Product Performance
- Monthly Sales Trends
- Country-wise Sales Analysis
- Top Selling Products

## Skills Demonstrated

- Data Cleaning
- Data Transformation
- Data Modeling
- DAX Measures
- Interactive Dashboard Development
- Business Intelligence Reporting
