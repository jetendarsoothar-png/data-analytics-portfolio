# ☕ Coffee Shop Sales Dashboard

## Project Overview

An interactive **Excel dashboard** developed to analyze coffee shop sales data and provide insights into transactions, quantity sold, revenue, profit, product categories, cities, and sales trends.

## Tools Used

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Excel Formulas
- Data Cleaning
- Data Visualization

## Dashboard Analysis

This dashboard provides insights into:

- Total Transactions
- Total Quantity Sold
- Total Revenue
- Total Profit
- Category-wise Transactions
- Weekly Transaction Trends
- Monthly Transactions
- Yearly Revenue Percentage
- Revenue by Category
- Revenue by City
- Monthly Profit & Revenue
- Year-wise and Month-wise Sales Analysis

## Skills Demonstrated

- Data Cleaning
- Data Analysis
- Excel Pivot Tables
- Pivot Charts
- KPI Development
- Interactive Dashboard Development
- Sales & Revenue Analysis
- Trend Analysis
- Business Intelligence Reporting
- Data Visualization
